# qcsui.github.io

Personal site, hand-built static HTML/Tailwind (no Jekyll, no build step —
`.nojekyll` tells GitHub Pages to serve the files as-is).

- `index.html` — homepage: about, projects, publications, contact
- `agentic-hil/` — interactive walkthrough demo for the *Agentic HIL*
  project (ECCE 2026)

## Local preview

```
python3 -m http.server 8080
```

then open `http://localhost:8080/`.
